# NYC Taxi Data Analysis using Pandas

## Project Overview

This project analyses 2023 New York City Yellow Taxi trip data using Python and Pandas to identify patterns in taxi demand, revenue, trip behaviour, pricing, payment methods, and high-demand locations.

The analysis includes data cleaning, exploratory data analysis (EDA), financial analysis, temporal analysis, and geographical analysis.

## Business Problem

The objective of this project is to analyse NYC Yellow Taxi trip data and generate insights that can support:

- Taxi demand planning
- Revenue analysis
- Peak-hour operations
- Driver and taxi positioning
- High-demand pickup and drop-off locations
- Pricing and trip efficiency analysis

## Dataset

The project uses NYC Yellow Taxi trip records for 2023.

The analysis works with monthly Parquet files and uses sampling to make the analysis computationally manageable.

## Data Cleaning

The project includes:

- Loading monthly Parquet files
- Combining sampled datasets
- Missing-value analysis
- Missing-value treatment
- Duplicate and unnecessary-column handling
- Outlier analysis
- Filtering invalid fare, distance and tip values
- Date/time preparation

## Key Findings

The analysis identifies several patterns in NYC taxi operations, including:

- Peak taxi demand around evening hours
- Differences in demand between weekdays and weekends
- Quarterly and monthly revenue patterns
- Relationship between trip distance, fare amount and tip amount
- Credit card as a major payment method
- High-demand pickup locations including airport-related zones
- Differences between daytime and nighttime revenue
- Variation in fare per mile across trip distances
